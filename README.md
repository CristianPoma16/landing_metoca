# Me Toca — Página web

Página empresarial estática para **Cristian Poma / Me Toca**.

## Archivos

- `index.html` — estructura y contenido.
- `style.css` — diseño responsive y paleta de colores.
- `script.js` — menú móvil, animaciones y año automático.
- `assets/MeToca.png` — logotipo horizontal.
- `assets/MeTocaISOTIPO.png` — isotipo usado como favicon.

## Antes de publicar

En `index.html`, reemplaza:

- `TU_CORREO@EJEMPLO.COM`
- los enlaces `#` de Facebook, Instagram y LinkedIn.
- el enlace de WhatsApp por el número real.

La página no necesita backend ni base de datos y está lista para GitHub Pages.
